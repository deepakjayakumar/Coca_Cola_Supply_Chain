# Agentic AI Supply Chain PoC

This is a proof of concept for an agentic AI that plans and optimizes a beverage supply chain.

## How to use

Simply enter a request in the text box and click "Run Agent". The AI will query the Snowflake database and return an optimized delivery plan.
